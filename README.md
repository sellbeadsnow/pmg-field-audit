# PMG Field Audit V3 UX update

Replace these three files in the existing GitHub repository:

- `index.html`
- `css/app.css`
- `js/app.js`

Do not replace the existing `data` folder. V3 continues to load:

- `data/stations.json`
- `data/devices.json`
- `data/locations.json`
- `data/lookups.json`

## Included

- Microsoft Lists-style left filter pane
- Multi-select filters
- Location, facility, business-line, department, status, device-type, data-health, and completion filters
- Sortable headers and active sort highlighting
- Mobile filter drawer
- Clickable audit breadcrumb filters
- Searchable and department-filtered station queue
- Location-route progress
- Station-completion progress
- Device status cards
- Collapsed full-station edit form
- Quick Pass, Flag, Previous, Skip, Save, and Save & Next actions
- Local browser edit persistence and JSON export
